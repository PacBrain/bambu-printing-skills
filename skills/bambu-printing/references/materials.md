# 材料选择与准备

资料状态见来源索引：既有 Wiki 摘要并未全部在本轮重读。编号见 [sources.md](sources.md)。本表是决策摘要，不是通用温度表；具体牌号的 TDS、硬件适配和对应机型配置决定实际参数。

| 材料 | 决策重点与打印前核对 | 来源 |
|---|---|---|
| PLA Basic / Matte / Tough | 外观、尺寸试配与常规原型；不同系列韧性和表面不同。核对板型、腔内积热；新开封 Basic 不一律要求烘干 | B02 |
| PLA Silk / Silk+ | 光泽受外墙速度影响，不以光泽推断层间强度；核对干燥、专用预设、实际速度变化 | B02 |

| ABS / ASA | 收缩、翘曲与腔温；核对封闭机型、板面与胶、通风。ASA 可作为耐候用途候选 | B05 |
| PC / PC FR | 耐热与工程用途，核对干燥、腔温、机器和板型；FR 原料不自动使成品符合防火认证 | B05 |
| PA6-GF / PAHT-CF 等尼龙 | 湿度影响打印及成品性能；干燥、密封送料、硬化喷嘴；比较性能时记录干燥/调湿状态 | B06、B07 |

## 干燥不是一个统一数字

先查牌号和设备，再取温度与时间：热风烘箱、热床、AMS 2 Pro、AMS HT 不可互换设置。设备达到最高温也未必满足高温材料的深度干燥要求。[B11、B12]

- 第三方线盘和原厂线盘耐温可能不同。
- 干燥后仍需密封防潮，高吸湿材料在打印期间也应保持干燥。
- 混装低软化温度材料时，不能直接启动另一种材料的高温干燥程序。
- 干燥中自动送料、静态/旋转干燥、专用 TPU 出口是不同模式，按机型和固件核对。
- 拉丝、气泡、粗糙是受潮线索，不是单一确诊依据；同时排查残料、喷嘴和流量。

作业记录包含牌号、喷嘴/板型、预设版本、打印温度、最大体积流量、干燥设备与参数、材料状态。没有校准实测时采用匹配官方基线并说明。供应商机械数据不等于实际打印件的性能。

PLA 腔内积热可能引发热蠕变堵塞。开门/通风建议结合机型、环境和板温，不推广为所有材料开门打印。[B02、B05]

## 用具体牌号与硬件组成一条可执行选择

选择记录至少写成“品牌/系列 + 机器 + 喷嘴口径/材质/流量类型 + 送料路径 + 板型”，然后读取该组合的机型子预设。基类 `@base` 只提供部分参数，不能直接当所有机器的完整工艺。

- **Bambu TPU for AMS**：02.08.04.57 官方基类说明限定为足够硬、适配 AMS 的 TPU（不低于 55D），明确不能用它切普通软 TPU。这个硬度条件也不使任意第三方 TPU 自动获得 AMS 兼容性；仍需具体牌号的送料说明。[B38]
- **Bambu PETG HF**：有独立的系列预设及板温/流量项；不将 Generic PETG 或 PETG Basic 的参数仅改名后当 HF 配置。最终值取机器子预设及当前安装版本，特别核对实际板型。[B39]
- **Bambu PLA-CF、PAHT-CF 等填料系列**：分别核对官方喷嘴材质、口径和送料限制。硬化喷嘴解决磨耗的一部分，不能证明 AMS、热端温度或干燥能力也相容。[B07、B10]
- **第三方材料**：优先使用该品牌/系列的官方 TDS 和匹配机型预设；只有 Generic 基线时，明确“未校准基线”，记录必要的小试目标。不能把另一品牌的最大体积流量或干燥温度当已验证值。

引用强度/热变形数据时记录试样方向、干燥/调湿条件与测试方法；仅有材料数据表时不推断本模型的实际承载。

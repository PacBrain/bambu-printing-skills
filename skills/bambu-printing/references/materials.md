# 材料选择与准备

核对日期：2026-10-12。编号见 [sources.md](sources.md)。本表是决策摘要，不是通用温度表；具体牌号的 TDS、硬件适配和对应机型配置决定实际参数。

| 材料 | 决策重点与打印前核对 | 来源 |
|---|---|---|
| PLA Basic / Matte / Tough | 外观、尺寸试配与常规原型；不同系列韧性和表面不同。核对板型、腔内积热；新开封 Basic 不一律要求烘干 | B02 |
| PLA Silk / Silk+ | 光泽受外墙速度影响，不以光泽推断层间强度；核对干燥、专用预设、实际速度变化 | B02 |
| PLA-CF / Glow / 木粉等 | 磨耗、堵塞、送料限制各异；核对硬化喷嘴、最小口径、AMS 型号，含填料系列常不适合 0.2 mm | B02、B10 |
| PLA Aero | 发泡量随温度变化，流量和密度强耦合；使用专用流程与试件，不照搬 Basic | B02 |
| PETG Basic / HF | 防潮、拉丝、层间结合；HF 不等于 Basic。干燥后再判断温度/回抽，降速不完全替代干燥 | B03 |
| TPU 85A / 90A / 95A HF | 硬度决定送料和喷嘴限制；使用适配的低阻力送料并保持干燥，普通软 TPU 不直接走常规 AMS 自动送料 | B04 |
| TPU for AMS | 针对自动送料的特定牌号，与普通 TPU 区分，仍核对板型和喷嘴 | B04 |
| ABS / ASA | 收缩、翘曲与腔温；核对封闭机型、板面与胶、通风。ASA 可作为耐候用途候选 | B05 |
| PC / PC FR | 耐热与工程用途，核对干燥、腔温、机器和板型；FR 原料不自动使成品符合防火认证 | B05 |
| PA6-GF / PAHT-CF 等尼龙 | 湿度影响打印及成品性能；干燥、密封送料、硬化喷嘴；比较性能时记录干燥/调湿状态 | B06、B07 |
| ASA-CF / ABS-GF | 稳定性伴随磨耗和送料限制；根据牌号确认喷嘴和 AMS，不按“都是 CF”推断 | B06、B07 |
| PET-CF / PPA-CF / PPS-CF / PA6-CF | 核对机器温度、送料脆性、干燥能力。部分牌号不支持 AMS 自动送料；AMS HT 作干燥箱不等于自动送料 | B08 |
| 专用支撑材料 / PVA | 匹配主体、温度与剥离/溶解方式；支撑料不是结构料，PVA 不直接作为 PETG 支撑方案 | B09、B17 |

## 干燥不是一个统一数字

先查牌号和设备，再取温度与时间：热风烘箱、热床、AMS 2 Pro、AMS HT 不可互换设置。设备达到最高温也未必满足高温材料的深度干燥要求。[B11、B12]

- 第三方线盘和原厂线盘耐温可能不同。
- 干燥后仍需密封防潮，高吸湿材料在打印期间也应保持干燥。
- 混装低软化温度材料时，不能直接启动另一种材料的高温干燥程序。
- 干燥中自动送料、静态/旋转干燥、专用 TPU 出口是不同模式，按机型和固件核对。
- 拉丝、气泡、粗糙是受潮线索，不是单一确诊依据；同时排查残料、喷嘴和流量。

作业记录包含牌号、喷嘴/板型、预设版本、打印温度、最大体积流量、干燥设备与参数、材料状态。没有校准实测时采用匹配官方基线并说明。供应商机械数据不等于实际打印件的性能。

PLA 腔内积热可能引发热蠕变堵塞。开门/通风建议结合机型、环境和板温，不推广为所有材料开门打印。[B02、B05]

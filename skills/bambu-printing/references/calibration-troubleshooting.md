# 校准、缺陷与维护

来源 B02–B14、B20、B22。先取得照片、位置、开始层数、材料/硬件、实际工程及日志；从证据提出假设。

**Flow ratio** 调整稳定挤出量；**Flow Dynamics / K** 补偿加减速的压力响应。按稳定挤出量和压力响应分别校准。[B13、B14]

先检查喷嘴/送料、干燥、板面与机器基础校准，再考虑材料流量校准。自动校准按机型、传感器和喷嘴选择，并记录真实校准块/线的观察结果。匹配的官方预设作为未实测基线。

| 症状 | 优先核查 | 下一步实验 |
|---|---|---|
| 首层不粘、翘曲 | 板型、清洁、底面、首层路径、板温与环境 | 调整附着/方向，高收缩材料查腔温 |
| 拉丝、气泡、粗糙 | 受潮、残料、温度、空移 | 干燥后小试，再限定调整温度/回抽 |
| 欠挤出、缺线 | 堵头、送料、线盘、体积流量、磨损 | 降低超能力流量，按机型维护 |
| PLA 长时间后堵塞 | 腔内积热、板温、环境与散热 | 核查官方通风条件，不套高温料策略 |
| 桥接下垂、悬垂差 | 朝向、跨度、局部速度、冷却 | 局部减速或支撑，避免全模型盲目降速 |
| 顶面有孔 | 壳厚、下方填充跨度、流量 | 查看封顶首层，再增加必要壳层/支撑 |
| 层间脆裂 | 材料状态、受力方向、温度、冷却 | 用试片验证，填充不是唯一原因 |
| 光泽不均 | 实际速度/流量、材料系列 | Silk 查看局部变速，不全部归因受潮 |
| 撞击声 | 填充交叉、翘曲、碰撞、挤出异常 | 检查路径/实况，不直接当正常噪声 |

一次改少量因素，记录前后与真实观察。切换高熔点/纤维材料后打印低温或柔性料，残留可能增加阻力；按机型清堵、冷拉和喷嘴更换指南操作，不把某个温度推广为所有机器的维修命令。[B04、B22]

高温、运动部件和纤维后处理防护按具体操作指南。没有设备现场状态时，不假定已经冷却/空载。升级固件、拆机和启动打印属于独立授权动作。

## 校准顺序与适用例外

机器基础状态、材料状态、稳定挤出量、动态压力响应分别记录。换喷嘴/热端、材料系列、关键温度或材料状态后判断是否需要重新验证，而不机械地每个作业重做所有校准。

自动校准是否可用取决于机型、固件、喷嘴、材料与板面条件，查看当次界面提示和机型文档。传感器无法可靠读数或该组合未支持时，用官方手动流程与试件；根据试件或传感器结果记录校准状态。K 值和 flow ratio 的配置保存位置不同，重开工程并检查实际选用的结果。[B13、B14]

温度塔、最大体积流量或尺寸补偿试件属于针对性实验：先定义目标和可观察的失效点，再在材料/硬件允许范围内变化。待实测时先提供试件与记录表，结果标记为 `not_run`；完成测量后选择参数。

## 软件问题与实物缺陷分开排查

导入后尺寸错先查源单位和变换；参数重开后恢复先查系统预设差异和局部覆盖；切片报错先看模型拓扑、配置兼容、层高/支撑组合；导出缺失则检查本次进程、图形访问、日志与输出目录。保留能重现问题的最小工程、版本/渠道和日志，不把全部失败都归为材料受潮。

修复后重新运行引发问题的最小场景，再回到完整工程验收。定位错误时保留官方 G-code、兼容列表与局部设置，按实际原因修复。

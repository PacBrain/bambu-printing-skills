# 切片决策与省料

来源 B01、B15–B18、B20、B25–B30，见 [sources.md](sources.md)。这是选择方法，不是所有模型共用配方。

## 几何、方向和参数

先确认单位、封闭性、法线、薄壁和底面；按载荷方向、关键接触面、层间结合和支撑可拆性选方向。减少支撑有时比降低填充更省料。需要切割/加孔/改外形时尊重用户授权。

| 参数 | 影响与检查 |
|---|---|
| Layer height | 小层高改善 Z 向阶梯，增加时间，不改变 XY 喷嘴分辨率。使用实际喷嘴范围，首层可不同。[B26] |
| Line width | 优先继承官方值；变宽影响细节、壁厚、流量与接触。桥接自由挤出不等于压平线宽。[B29] |
| Wall loops | 对壳体和局部载荷重要；实际厚度受线宽/墙生成器影响，喷嘴直径乘圈数不是精确值。 |
| Top/bottom shells | 同时检查层数和最小厚度；稀疏填充上的封顶首层有桥接工况，平整度依赖支撑跨度。 |
| Sparse infill | 封闭 CAD 不等于实心；密度、路径、壳层、方向共同影响用料与强度。 |
| Infill/wall overlap | 太小结合不足，过大会鼓包，不为强度无限增加。[B25] |
| Speed / flow | 外墙、顶面、悬垂分别考虑；速度受最大体积流量限制，用预览查实际值。[B20、B28] |
| Cooling | 风量、层时间、桥接/悬垂冷却因材料而异，降温加风并非通用修复。[B15] |
| Seam | 放在非关键接触/展示区并逐层检查；scarf seam 有悬垂等适用限制。[B16] |

## 填充选择

- Gyroid：同层无交叉线，空间方向支撑较均衡；路径较复杂，高密度高速关注振动。[B30]
- Grid：生成快，但交叉处可能堆料、擦碰。[B30]
- Cubic / Adaptive Cubic：三维支撑或分布式省料候选，检查局部封顶跨度。[B30]
- Lightning：主要服务封顶，适合低承载装饰件，不默认用于受力承托件。[B30]

工程建议：从官方工艺出发选少量候选，比较真实切片重量、时间、顶层跨度和关键部位。10%/15% 等低填充是项目选值，不保证最终强度。

## 支撑与附着

检查实际局部悬空；比较正常/树状、仅平台/所有区域、绘制与屏蔽。确保可拆且不损伤关键表面。主体材料支撑需适当界面间隙，不能套用异材支撑零间隙。[B17]

专用支撑通常只用于界面以减少换料和消耗，需匹配主体/温度。比较总用料包括冲刷、擦料塔、支撑和裙边。[B09、B17]

Brim 控制宽度、对象间隙、内外位置，它不是悬垂支撑。先核查清洁、板型、温度与底面；实际间隙还受象脚补偿影响。[B18]

## 完成预览

逐层看首层、内部、桥接、封顶、薄壁、细柱和最高层；结合线型/速度/层高/流量。检查对象/部件/修改器覆盖并保存完整工程。复杂曲面不无依据开启熨烫。

# 硬件与打印空间

依据 B10、B12、B27、B31 和本机官方 profile；核对日期：2026-10-12。

## 硬件身份

确认完整型号、喷嘴直径/材质、标准/高流量/E3D 热端、打印板、AMS 型号和实际线材。相同喷嘴直径不表示流量或回抽设置相同。`printer_extruder_variant`、`print_extruder_variant`、`filament_extruder_variant` 是变体数据，不可截断任意长度相同的数组。

板型决定温度和附着。CLI 从 STL 创建工程不能假定继承 GUI 板型：本机 2.8.4 测试默认出现 Cool Plate，工具因此要求显式 `--bed` 并检查输出 `curr_bed_type`。

AMS 可装材料、可自动送料、可边打边烘是独立问题。普通柔性 TPU、脆性复合料、粗糙磨蚀性材料的限制分别核对。[B04、B08、B10、B12]

## 同盘与逐件

使用 `printable_area`、`printable_height`、排除区域及最终单位/朝向计算，不能用平台面积相除。考虑裙边、支撑、擦料塔、校准线和检测/擦拭占位；生成路径后再次检查。

`preflight` 使用保守 XY 包围盒加裙边缓冲。通过不证明工具路径可达，拒绝也可能需更精细排布。新增区域由 `additional_exclude_areas` 提供。

- **按层**：同一高度多个对象依次完成，再整体升高，适合许多成对较高零件。
- **逐件**：除 XY 间隔，还受方向性工具头净空、横杆、上盖限制。[B27]

不能因为平面放得下就启用逐件。工具采用保守半径/横杆高度筛查；复杂布局还须原生碰撞检查，报告注明顺序。

## H2S 本机实例

已读取的官方 `Bambu Lab H2S 0.4 nozzle` 平台 340 × 320 mm，高 340 mm，标准单喷嘴；`wrapping_exclude_area` 在后侧局部。运行时重新读取，此数据不适用于 H2D 双喷嘴范围。

切片支持不等于已连接客户机器，也不证明固件、板面清洁和材料状态已验证。

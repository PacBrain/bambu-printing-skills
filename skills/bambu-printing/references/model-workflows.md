# 模型导入、修复与工程结构

适用：Bambu Studio 2.8.x；本轮读取 02.08.04.57 源码相关段落，见 B34、B37、B40、B41。以下为原生软件操作方法；自动脚本仅接收清单内 STL 或受限原生工程。

## 导入之前保留什么

- 保留原始 CAD/网格和原生工程，修复在副本上进行。STL 只有网格，不能代替包含材料、摆放、涂色及局部设置的原生 `.3mf`。
- 导入已有 `.3mf` 时，先确认是在打开完整工程还是仅导入几何。来自其他软件的 3MF 可携带几何但未必具有可用的 Bambu 工艺设置；只有路径的板切片文件无法恢复可编辑几何。[B21、B40]
- 用一条已知长度核对单位，并记录原始尺寸。STL 不提供可靠单位；脚本要求每个对象显式指定 mm/cm/m/inch。缩放一次后再旋转和定位，不能先预检毫米网格、再把原始英寸 STL 交给切片器。
- STEP 导入需检查离散后的曲面、薄壁与小孔；网格简化可减轻计算负担，但三角形减少不是质量提高。比较关键边界、孔径、接触面及切片轮廓，而不是只看面数。[B37、B41]

## 修复需要证明形状仍然正确

先定位开放边、非流形边、翻面、重复面、自交或零面积面。区分设计孔洞与意外缺口；封闭网格和正体积只证明部分拓扑条件，不能证明没有自交、壁厚足够或设计正确。

原生修复能力受平台和安装组件影响；02.08.04.57 对象列表中包含 Windows SDK 修复路径，不承诺每个平台同一按钮等效。不可用时回到 CAD/网格工具修复，不通过忽略警告交付。[B34]

修复后比较对象数、尺寸、体积、关键剖面和薄壁，重新切片看缺层、内部空洞、异常实心区。重网格、切割、简化可能改变面片索引；重新核查原有涂色、支撑绘制、接缝绘制是否仍覆盖正确区域。脚本预检不会自动修补输入几何。

## 对象树决定局部设置的意义

| 结构 | 适合的用途 | 要核对的结果 |
|---|---|---|
| 对象 object / 实例 instance | 独立摆放的零件或副本 | 实际可打印实例数、坐标、平台归属；不要把资源 mesh 数当零件数 |
| 部件 part | 同一对象中的实体区域，例如双色嵌件 | 相对位置、材料分配和局部参数；拆为对象可能改变平台落点 |
| 修改器 modifier | 在相交区域调整填充、墙数等受支持参数 | 修改器自身不是待打印实体；切片预览确认作用边界 |
| 负体积 negative part | 局部减料、切孔 | 修改的是切片几何；另存工程并检查孔是否贯通 |
| 支撑强制/屏蔽体 | 指定或禁止局部支撑 | 与普通参数修改器分开检查，确认没有孤立悬空面 |

这些类型在官方对象列表和序列化结构中分别保存。[B34、B40] 不为实现局部填充而重新导出 STL 丢失全部层级；也不要仅修改全局设置就声称对象覆盖已更新。

装配导入后核查部件关系，再决定拆为对象还是保留多部件对象。修改器、负体积和可打印部件分别计数；输出核对保留名称/身份、实例变换和局部设置。批量操作先用一个有代表性的零件检查结果，再应用到其余对象。

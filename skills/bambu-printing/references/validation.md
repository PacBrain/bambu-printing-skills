# 验证记录

2026-10-12；macOS arm64，Bambu Studio 02.08.04.57。Python 3.14，NumPy 2.5.4、trimesh 5.1.1、Shapely 2.2.0。其他平台/版本属于未实测，不承诺等效。

## 已运行

- 16 项 unittest：继承/include 优先级、循环/缺父项、保留官方 G-code、自定义差异、废弃键拒绝、缺少运行环境、中文/空格路径、无单位、英寸换算后超界、裙边越界、禁止区、开放网格、重叠、逐件净空、3MF 多文件变换，以及仅含路径的 3MF 不误报为可编辑模型。
- 合成 20 × 20 × 12 mm 模型，实际 H2S 0.4 标准热端/PLA Basic/纹理 PEI 切片，生成 60 层路径并由原生 Studio 打开。
- 解析原生 3MF Production Extension，正确恢复原始尺寸和打印平台位置。
- 本地应用验证了非默认填充、墙数、封顶、接缝、裙边等改动：修复 `different_settings_to_system` 后，GUI 重开保留设置；废弃顶面单墙键被现行枚举替代。
- 原生板切片导出验证包含 H2S 机器标识 `O1S`、0.4 mm 标准热端、路径、时间/质量和 MD5 校验；可编辑工程与板切片文件分开交付。

项目特定模型、截图和 G-code 不放入公开仓库。上述 GUI 验证是软件证据，不是设备打印试验。

## 明确边界

- 未实际启动打印机；强度、层间结合、舒适性和耐热未实测。
- 高流量、多热端、多材料自动切片未验证，脚本拒绝相关自动配置；知识参考不代表所有组合已测试。
- 预检为保守包围盒和网格拓扑，不是全路径碰撞、精确自交或壁厚证明。
- 本机 CLI 的图形导出需要 macOS 图形访问；成功生成路径不等于缩略图/工程导出成功。
- 已知 H2S 官方 `T65535` 解析日志、体积标签和机器 ID 边界见 [automation.md](automation.md)。日志保留，不把问题删掉后宣称零错误。

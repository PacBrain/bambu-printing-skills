# 高级原生工作流

这些工作流有文档或源码依据，不代表捆绑脚本已自动验证。使用实际安装版本的 Studio 完成操作和预览；版本/渠道及验证状态写入交付记录。[B32–B36、B40]

## 多盘

先按实际机器、板型、材料温度和交付批次分组，建立每盘对象清单。记录盘索引与盘名，并核对每盘材料分配、局部设置、位置及打印顺序。移动对象后重新检查落点、支撑、擦料塔和禁止区。

官方 CLI `--slice 0` 表示全部盘，正整数选择对应盘；这不等于一次物理连续打印。`--export-3mf` 导出项目，`--export-slicedata` 导出缓存切片数据，`--export-settings` 导出设置，三者不可互换。[B24] 本技能脚本不自动处理多盘；在原生软件中逐盘验收并分别导出执行文件，完整可编辑工程保留全部盘。

## 多材料与多喷头

工程中的材料槽、设备 AMS 槽、物理喷头是不同映射。对每种材料记录品牌/系列、颜色、送料路径、喷嘴直径与热端类型，再检查对象/部件/涂色区域实际使用的槽。显示颜色相同不能证明材料相同。

单喷头多材料需要兼容的温度范围、送料和换料策略；双/多喷头还需检查喷头专属打印范围、共享范围、停放位置、各喷头口径与材料分组。不要把单喷头平台轮廓复制成多喷头范围。Studio 源码对喷头独占区及材料分配有专门约束。[B35]

先预览所有层的材料和工具切换，特别检查小面积嵌件、桥接、支撑界面和最后一次换料。若更新机型或删改材料槽，重新确认映射。保存完整工程，并在重新打开后复核局部设置；本技能的 `slice` / `reslice` 不负责这类工程。

## 支撑界面、冲刷和擦料塔

支撑主体与界面可以使用不同材料；只在界面使用专用支撑料常能减少换料，但仍要检查材料相容性、界面层数、Z/XY 间隙和拆除方向。不同材料可采用的间隙不应套到同材支撑。[B09、B17]

冲刷处理换料残留，擦料塔用于恢复稳定挤出等操作；二者不是同一用料项。省料比较应同时报告模型、支撑、冲刷、擦料塔及附着结构的质量和时间，并确认软件统计是否已经包含某一项，避免重复相加。材料之间的冲刷需求有方向性，不能只用一个颜色数量估算。

冲刷到填充、支撑或指定对象会改变那些区域的材料组成与颜色；承力部位、薄壁/透光表面及可剥离界面需特别检查。02.08.04.57 配置说明中，这些冲刷选项依赖擦料塔启用；不能通过简单取消塔来保证省料。[B33] 对减少换料、改变方向、合并同材区域的候选实际切片比较，不以取消冲刷作为默认优化。

检查塔自身的附着、稳定性及整个挤出路径占位。多喷头并不自动意味着无需冲刷或塔；以对应机型的预设与切片结果判断。[B36]

## 可变层高

曲面缓坡的阶梯较明显时，可变层高可把较细层集中在重要表面。先固定模型单位、尺度和朝向，再用原生 Variable layer height 的 Adaptive、局部编辑和 Smooth；旋转/缩放改变 Z 范围后重新检查层高曲线。[B35]

确认最小/最大层高符合选定喷嘴和材料，逐层核查过渡、封顶、桥接和支撑。对多个对象、擦料塔、不同喷嘴或特殊支撑组合，先运行当前版本兼容检查。02.08.04.57 源码明确拒绝 Organic 支撑与可变层高组合；塔与多个对象要求层序匹配，不应把旧资料中“所有可变层高均不支持塔”当现行通则。[B36]

保存包含层高曲线的原生工程；普通 STL 和单独的全局层高参数不保存这项编辑。[B40] 验收看重新打开后的层高预览和实际切片，不只看界面按钮曾被开启。

## 版本与渠道

本轮读取的 release 将 `v02.08.04.57` 标为 Public Beta，`2.8.2.61` 标为 Public Release；这描述核对时的版本，不承诺未来最新版。[B32] Beta release 特别指出其保存的 3MF 当时暂不支持上传 MakerWorld。需要交给其他机器/人员或上传的平台时，核对目标环境，保留原件，在目标版本重开并重切片；不要自行升级或降级用户软件来掩盖兼容问题。
